# Grok Build Desktop 0.5.43

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.43 điều chỉnh phần xem trước tệp (File Preview) và duyệt thay đổi (Review) tự động co giãn và xuống dòng responsive theo kích thước khung chứa khi thay đổi kích thước; thêm nút bật/tắt tự động xuống dòng (Word Wrap); các tệp Windows chưa được ký số. | Release 0.5.43 enables responsive word wrapping and adaptive resizing for the File Preview and Review panes; adds an interactive Word Wrap toggle button; the Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Khung xem trước tệp (`.editor-body`) và nội dung dòng code (`.code-line-content`) tự động co giãn và ngắt dòng thông minh khi người dùng kéo thanh phân chia (splitter) hoặc thay đổi kích thước cửa sổ, không còn bị tràn ngang hay bắt buộc phải cuộn ngang để đọc nội dung. | The File Preview pane (`.editor-body`) and code lines (`.code-line-content`) now resize and soft-wrap responsively when dragging splitters or resizing the window, eliminating horizontal overflow and unnecessary horizontal scrolling. |
| Thêm nút bấm **"Tự động xuống dòng"** (`#btnToggleWrap`) trên thanh tiêu đề xem trước tệp, hỗ trợ bật/tắt wrap nhanh chóng, có icon `wrap` đồng bộ và lưu trạng thái vào cấu hình layout. | Added a **"Toggle word wrap"** button (`#btnToggleWrap`) in the file preview header with a matching `wrap` icon and persisted layout preference. |
| Phần duyệt thay đổi diff (`.diff-body`, `.diff-pane`) cũng được cập nhật tự động co giãn và xuống dòng nhất quán với trình xem tệp. | The Review diff view (`.diff-body`, `.diff-pane`) was also updated to wrap and adapt consistently with the file viewer. |
