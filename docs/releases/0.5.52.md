# Grok Build Desktop 0.5.52

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.52 dựng file Markdown (kế hoạch, báo cáo, README) thành tài liệu đọc được sau khi Grok viết xong: tiêu đề, in đậm, bảng, code màu và sơ đồ, thay vì chỉ hiện diff/mã nguồn. | Release 0.5.52 renders Markdown files (plans, reports, README) as readable documents after Grok finishes writing them: headings, bold, tables, colored code and diagrams, instead of a raw diff or source dump. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Thẻ công cụ ghi `.md` chuyển sang xem tài liệu khi tool hoàn tất; vẫn có nút Diff nếu cần đối chiếu thay đổi. | A completed `.md` write shows the document in the tool row, with a Diff toggle when you need the change list. |
| Cửa sổ Tệp mặc định xem Markdown đã dựng (bảng, tiêu đề màu, code highlight, sơ đồ Mermaid); nút Mã nguồn quay lại file thô. | The Files pane defaults to rendered Markdown (tables, colored headings, highlighted code, Mermaid diagrams); Source switches back to the raw file. |
| Bảng Xem thay đổi có nút Tài liệu cho file Markdown để đọc nội dung đầy đủ trước khi chấp nhận/từ chối hunk. | The Review pane adds a Document button for Markdown files so you can read the full content before accepting or rejecting hunks. |

|---|---|
