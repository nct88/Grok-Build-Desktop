# Grok Build Desktop 0.5.65

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.65 cho phép chọn Grok 4.7 trên chip model sau CLI 1.0.40+ và hiển thị cửa sổ ngữ cảnh theo occupancy hiện tại, không còn kẹp 100% vì token cộng dồn cả phiên. | Release 0.5.65 lets the model chip select Grok 4.7 after CLI 1.0.40+ and shows the context-window gauge from current occupancy instead of clamping at 100% from cumulative billed tokens. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Catalog model theo CLI: fallback và chip mặc định `grok-4.7` / `grok-4.7-build-fast`; preference `grok-4.6` đã lưu chỉ áp một lần mỗi lần connect, nên bấm 4.7 không bị kéo lại 4.6. | Live CLI catalog: fallback and default chip include `grok-4.7` / `grok-4.7-build-fast`; a saved `grok-4.6` preference applies once per connect so picking 4.7 stays selected. |
| Cửa sổ ngữ cảnh dùng ACP `usage_update` hoặc `_meta.totalTokens` chia `context_window`. Token vào/ra cộng dồn vẫn ở khối Phiên hiện tại. | Context-window percent uses ACP `usage_update` or `_meta.totalTokens` over `context_window`. Cumulative input/output stay on the This session card. |
