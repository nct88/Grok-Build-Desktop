## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Trong khung chat, bên trái là dấu cộng, quyền truy cập và View usage. Bên phải là model kèm effort, micro và nút gửi hình tròn. Phía trên khung chỉ còn chọn dự án. | Inside the chat box, the left side is plus, permission, and View usage. The right side is model plus effort, the microphone, and a circular send button. Above the box, only the project picker remains. |
| Cột hội thoại dùng hết chiều ngang còn lại, không còn dừng quanh 780px. | The conversation column uses the remaining width and no longer stops near 780px. |
| View usage mở bằng tiêu đề, ID phiên, thư mục làm việc, model, effort và cửa sổ ngữ cảnh. Tab Context hiện mức chiếm chỗ dạng gọn. | View usage opens with title, session ID, working directory, model, effort, and the context window. The Context tab shows compact occupancy. |
| Cây tệp và khung xem trước thu gọn độc lập. Thu cả hai thì cột phải còn một ray hẹp. | The file tree and the preview collapse on their own. Collapsing both leaves a narrow rail. |
