# Grok Build Desktop 0.5.46

<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.46 ẩn thanh tab session trên khung chat. Chuyển dự án và cuộc trò chuyện bằng sidebar trái; các tệp Windows chưa được ký số. | Release 0.5.46 hides the session tab rail. Project and chat switching uses the left sidebar; the Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Thanh tab session trên timeline không còn hiện. Sidebar thư mục dự án và chat con là chỗ chuyển phiên. | The session tab rail above the timeline is hidden. The left sidebar project folders and nested chats are the switcher. |
| **New chat** trên sidebar tạo cuộc mới. Click thư mục đổi dự án; click chat con mở đúng phiên. Task đang chạy ở dự án khác vẫn giữ slot/queue/nội dung nền. | **New chat** in the sidebar starts a new conversation. Click a folder to switch project; click a nested chat to open that session. A running task in another project keeps its slot, queue and background content. |
| Cache session nội bộ (`sessionTabs`) giữ nguyên — chỉ bỏ UI thanh tab trùng với sidebar. | In-memory session cache (`sessionTabs`) is unchanged — only the duplicate tab rail UI is removed. |
