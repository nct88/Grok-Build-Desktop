# Grok Build Desktop 0.5.42

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.42 sửa đúng luồng chuyển dự án và cuộc trò chuyện ở thanh bên trái. Một task đang chạy trong Project A tiếp tục giữ agent slot, hàng đợi, thời gian chạy và nội dung nền khi người dùng mở Project B; các tệp Windows chưa được ký số. | Release 0.5.42 fixes project and chat switching in the left sidebar. A task running in Project A keeps its agent slot, queue, runtime and background content while the user opens Project B; the Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Chọn project header, project menu, project picker, Recents hoặc chat lồng nhau chỉ đổi phần trình bày và tab sở hữu; thao tác điều hướng không còn gọi reconnect, force restart hoặc stop task đang chạy. | Selecting a project header, project menu, project picker, Recents or nested chat now changes only presentation and tab ownership; navigation no longer reconnects, force-restarts or stops a running task. |
| Mỗi project/chat giữ riêng agent slot, trạng thái running, runtime, hàng đợi và event cache. Stream của task nền không xuất hiện trong project khác và được replay khi quay lại đúng project. | Each project/chat retains its own agent slot, running state, runtime, queue and event cache. Background task streams do not appear in another project and replay when returning to their owner. |
| Chat đã mở được khôi phục đúng tab; chat lưu sẵn có thể tái dùng tab project còn trống. Chunk stream cuối được flush trước snapshot để chuyển nhanh không làm mất nội dung vừa hiển thị. | Already-open chats restore their owning tab, while stored chats can reuse a pristine project tab. The final stream chunk is flushed before snapshotting so rapid navigation cannot lose newly displayed content. |
