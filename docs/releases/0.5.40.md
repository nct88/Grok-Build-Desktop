# Grok Build Desktop 0.5.40

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.40 giữ tác vụ chạy độc lập khi chuyển tab, bổ sung đổi tên tab, làm mới khu vực Files thành cây dự án riêng và tô màu cú pháp theo ngôn ngữ. Tiêu đề phiên chỉ còn tên dự án; danh mục lệnh Grok CLI và luồng tin cậy MCP cũng được mở rộng. Các tệp Windows chưa được ký số. | Release 0.5.40 preserves independent running tasks across tab switches, adds tab renaming, rebuilds Files as a dedicated project tree, and highlights source by language. The session header now shows only the project name, while Grok CLI commands and the MCP trust flow are expanded. The Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Chuyển tab không còn resume/stop agent ngoài ý muốn. Mỗi tab giữ tiến trình, hàng đợi prompt, thời gian chạy, sự kiện nền và nội dung cache riêng; tên tab có thể đổi trực tiếp và được lưu lại. | Switching tabs no longer resumes or stops agents unexpectedly. Each tab owns its runtime, prompt queue, elapsed time, buffered events and cached content; tab names can be edited directly and persist. |
| Tiêu đề phiên chỉ hiển thị tên dự án. Files có cột Project Explorer riêng với cây thư mục/tệp tải lười, thu gọn/làm mới/thử lại, trạng thái tải-rỗng-lỗi và nhãn ngôn ngữ trên từng tệp. | The session header shows only the project name. Files now has a dedicated Project Explorer column with a lazy folder/file tree, collapse/refresh/retry actions, loading/empty/error states and per-file language labels. |
| Preview có số dòng và màu cú pháp an toàn cho các định dạng lập trình, cấu hình và markup phổ biến; tệp lớn hoặc định dạng chưa hỗ trợ vẫn có fallback rõ ràng. | Preview now has line numbers and safe syntax coloring for common programming, configuration and markup formats, with clear fallbacks for large or unsupported files. |
| Menu `/` bao phủ thêm các lệnh Grok CLI có thể ánh xạ sang Desktop. `/hooks-trust` và Tools → MCP cho phép cấp/thu hồi tin cậy thư mục rồi kết nối lại MCP. | The `/` menu covers more Grok CLI commands that map cleanly to Desktop. `/hooks-trust` and Tools → MCP can grant/revoke folder trust and reconnect MCP. |
