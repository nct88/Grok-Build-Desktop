# Grok Build Desktop 0.5.66

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.66 sửa chip effort trên Grok 4.7: chọn Low, Medium hoặc High được giữ, không còn bị kéo về Extra High sau mỗi lần ACP cập nhật cấu hình. | Release 0.5.66 keeps the effort you pick on Grok 4.7. Low, Medium, and High stay selected instead of snapping back to Extra High on every ACP config update. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Lựa chọn của người dùng thắng echo cũ: bấm một mức effort thì lưu ngay và không áp lại effort đã lưu trên các bản cập nhật cấu hình sau đó. | A user pick wins over a stale echo: choosing an effort saves it immediately and does not re-apply the previous saved effort on later config updates. |
| Mức mặc định khi agent chưa gửi current value là option đánh dấu default (High trên Grok 4.7), không phải dòng đầu Extra High. | When the agent sends no current effort, the chip uses the option marked default (High on Grok 4.7), not the first row Extra High. |
