# Grok Build Desktop 0.5.54

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.54 đưa dự án đang trao đổi lên đầu sidebar, thêm mốc thời gian theo ngôn ngữ app, giữ nội dung khi cuộn xuống cuối hội thoại, và đồng bộ đọc chính tả theo Grok CLI 1.0.25. | Release 0.5.54 promotes the active project to the top of the sidebar, adds language-aware last-active ages, keeps the last messages visible when scrolling to the end of a conversation, and aligns dictation insertion with Grok CLI 1.0.25. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Bấm dự án hoặc cuộc trao đổi đưa thư mục đó lên dòng đầu sidebar; kéo-thả vẫn sắp xếp tay được. | Opening a project or nested chat moves that folder to the top of the sidebar; drag-and-drop still reorders manually. |
| Bên phải dự án và trao đổi hiện tuổi tương đối; EN `now`/`45m`/`7d`, VI `vừa xong`/`45p`/`7ng`. Đổi ngôn ngữ thì nhãn đổi theo. | Project and chat rows show a compact last-active age; EN `now`/`45m`/`7d`, VI `vừa xong`/`45p`/`7ng`. Switching language updates the labels. |
| Hội thoại dài pin tin cuối khi cuộn tới đáy, không để nội dung rơi vào khoảng trống ảo. | Long transcripts pin the last messages when you scroll to the bottom, so content is not lost in the virtualized spacer. |
| Nhập chính tả bằng giọng nói chèn đúng tại vị trí con trỏ hoặc vùng bôi chọn (chuẩn Grok CLI 1.0.25) thay vì luôn nối vào cuối. | Voice dictation inserts at the cursor position or replaces active selection (Grok CLI 1.0.25 parity) instead of always appending to the end. |
