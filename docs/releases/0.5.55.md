# Grok Build Desktop 0.5.55

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.55 mang đến trải nghiệm hiển thị Markdown trực tiếp theo thời gian thực khi stream câu trả lời, mở trình đọc tài liệu Markdown ngay trên panel phải khi nhấn vào file .md, và bổ sung công cụ dọn dẹp bản build cũ. | Release 0.5.55 introduces live Markdown rendering during assistant streaming, opens rendered document preview in the right pane when clicking .md files, and adds automated cleanup for old build artifacts. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Luồng trả lời của trợ lý hiển thị trực tiếp định dạng Markdown hoàn chỉnh (tiêu đề, in đậm, danh sách, bảng biểu, hộp code) ngay trong lúc stream thay vì hiện văn bản thô rồi mới đổi kiểu. | Assistant streaming renders full Markdown formatting (headings, bold, lists, tables, code blocks) in real time instead of showing raw syntax before converting. |
| Nhấn vào liên kết file .md trong giao diện session sẽ mở trực tiếp bản đọc tài liệu đã render trên panel bên phải, hỗ trợ nút chuyển đổi nhanh giữa Preview và Source. | Clicking .md file links in the session timeline opens the rendered document directly in the right preview panel, with a quick toggle between Preview and Source. |
| Bổ sung lệnh `npm run clean:dist` giúp tự động quét và dọn dẹp an toàn các file build và thư mục kiểm thử cũ, giải phóng dung lượng đĩa mà vẫn bảo toàn bản dựng hiện hành. | Added `npm run clean:dist` to automatically and safely clean up old build artifacts and test folders, freeing disk space while preserving the current build. |
| Cập nhật tương thích Grok Build CLI 1.0.34 (Memory GA, đồng bộ bảng màu heading Markdown, slash command catalog). | Updated compatibility with Grok Build CLI 1.0.34 (Memory GA, Markdown heading theme colors, slash command catalog). |
