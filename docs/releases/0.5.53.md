# Grok Build Desktop 0.5.53

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.53 sửa lỗi chấp nhận `plan.md` (và các file tool dùng đường dẫn tương đối) bị chặn `Path outside workspace is not allowed.` | Release 0.5.53 fixes Accept on `plan.md` (and other relative tool paths) failing with `Path outside workspace is not allowed.` |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Đường dẫn tương đối từ review/tool (`plan.md`) được resolve theo thư mục dự án đang mở, không theo thư mục chạy của Electron. | Relative review/tool paths such as `plan.md` resolve against the open project folder, not the Electron process working directory. |
| Ghi file khi Chấp nhận/Từ chối dùng cùng phạm vi thư mục với đọc file (dự án sidebar / recents), nên xác nhận diff không còn bị từ chối oan. | Accept/Reject writes use the same folder sandbox as file reads (sidebar project / recents), so confirming a diff is no longer rejected incorrectly. |

## Gói phát hành / Release artifacts

- `Grok-Build-Setup-0.5.53.exe` — NSIS Setup / Bộ cài NSIS
- `Grok-Build-0.5.53-win32-x64-portable.exe` — Portable executable / Bản portable EXE
- `Grok-Build-0.5.53-win32-x64.zip` — Portable ZIP / Bản ZIP giải nén
- `MANIFEST.json` — Sizes and SHA-256 / Kích thước và SHA-256

| Tiếng Việt | English |
|---|---|
| Các tệp Windows chưa được ký Authenticode và có thể kích hoạt cảnh báo SmartScreen. Hãy kiểm tra SHA-256 trong `MANIFEST.json` trước khi chạy. | The Windows artifacts are not Authenticode-signed and may trigger SmartScreen. Verify SHA-256 values in `MANIFEST.json` before running them. |
