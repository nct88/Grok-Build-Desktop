# Grok Build Desktop 0.5.50

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.50 đưa terminal tích hợp lên ConPTY/xterm, sửa nút titlebar tắt terminal, thêm menu chuột phải sidebar dự án/chat và spinner khi agent đang chạy. | Release 0.5.50 upgrades the integrated terminal to ConPTY/xterm, fixes the titlebar terminal toggle, adds a project/chat sidebar context menu, and shows a busy spinner while the agent is working. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Terminal dock dùng `node-pty`/ConPTY, mặc định PowerShell, và xterm.js với FitAddon: ANSI, resize và nhập liệu TUI đi hai chiều trong thư mục dự án. | The terminal dock uses `node-pty`/ConPTY, defaults to PowerShell, and renders with xterm.js plus FitAddon so ANSI, resize and TUI input flow both ways in the project folder. |
| Nút terminal trên titlebar đóng dock ở lần nhấn thứ hai; vùng kéo cửa sổ chỉ còn spacer, chuột kích hoạt bằng `pointerdown`. Output PTY nền không tự mở lại dock đã ẩn. | The titlebar terminal button closes the dock on the second press; window drag is limited to the spacer and mouse activation uses `pointerdown`. Background PTY output no longer reopens a hidden dock. |
| Chuột phải thư mục dự án: chat mới, mở thư mục, sao chép đường dẫn, mở IDE, gỡ khỏi danh sách. Chuột phải chat: đổi tên, di chuyển, sao chép ID/Markdown, xuất, xóa. Không clone Pin/Archive/Share của Codex vì Desktop không có API đó. | Right-click a project folder for new chat, open folder, copy path, open IDE, or remove from the list. Right-click a chat to rename, move, copy ID/Markdown, export, or delete. Codex Pin/Archive/Share items are omitted because Desktop has no API for them. |
| Spinner xoay góc phải tiêu đề cuộc thảo luận và hàng chat đang chạy; nền tối dùng vòng sáng, nền sáng dùng vòng tối. | A spinning indicator appears at the right of the conversation title and on the active running chat row; it is light on dark and dark on light. |
