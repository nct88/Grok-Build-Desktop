# Grok Build Desktop 0.5.58

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.58 giải quyết triệt để lỗi render Markdown khi inline code nằm lồng bên trong đường dẫn liên kết, loại bỏ hiện tượng hiển thị placeholder thành số '0' đơn độc, bảo toàn hiển thị trọn vẹn đường dẫn file và nhãn mã nguồn trên cả luồng giao diện và worker. | Release 0.5.58 completely fixes Markdown rendering when inline code spans are nested inside link labels, eliminating raw token placeholder '0' digits and preserving full document paths and code labels across both UI and worker threads. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Giải nén token Markdown đệ quy: thay thế cơ chế thay thế single-pass bằng vòng lặp while có kiểm soát (`guard < 10`), đảm bảo mọi token lồng nhau (như thẻ `<code>` nằm trong `<a>` của liên kết file/URL) được bung hoàn toàn trước khi gán vào DOM. | Recursive Markdown token unpack: replaces single-pass token replacement with a guarded while loop (`guard < 10`), guaranteeing nested tokens (such as `<code>` spans inside file/URL `<a>` tags) are fully resolved before DOM insertion. |
| Đồng bộ worker xử lý nền: cập nhật hàm `renderMarkdown` trong `contentWorker.js` tương thích tuyệt đối với renderer luồng chính, ngăn ngừa hiện tượng giật hiển thị hoặc sai lệch định dạng khi render ngoài luồng. | Off-thread worker parity: updates `renderMarkdown` in `contentWorker.js` to match the main-thread parser exactly, preventing formatting discrepancies during off-thread rendering. |
| Bổ sung kiểm thử hồi quy: thêm assertion kiểm tra tự động trong bộ test E2E (`e2e-desktop.mjs`) bảo đảm các đường dẫn tài liệu dạng `[`docs/06-ADMIN_CMS_CANONICAL_SPEC.md`](docs/...)` không bao giờ bị render thành số `0`. | Regression test coverage: adds automated E2E assertion in `e2e-desktop.mjs` ensuring code-in-link document paths never render as bare '0' tokens. |
