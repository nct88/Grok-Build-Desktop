# Grok Build Desktop 0.5.44

<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.44 sửa lỗi định danh và đóng dấu biểu tượng ứng dụng Windows PE (App Icon & Metadata) trên file thực thi; tự động co giãn và ngắt dòng nội dung tệp xem trước; các tệp Windows chưa được ký số. | Release 0.5.44 fixes Windows PE executable icon and product metadata stamping; ensures responsive word wrapping for file previews; the Windows artifacts are unsigned. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Cập nhật cơ chế tìm kiếm `rcedit` đa môi trường, đảm bảo biểu tượng ứng dụng Grok Build chính thức được đóng dấu chắc chắn vào tệp `Grok Build.exe`, bộ cài NSIS và shortcut Desktop. | Updated cross-environment `rcedit` discovery to guarantee the official Grok Build application icon and PE metadata are properly stamped into `Grok Build.exe`, NSIS setups, and shortcuts. |
| Khung xem trước tệp và duyệt thay đổi tự động co giãn dòng và ngắt dòng thông minh khi thay đổi kích thước khung chứa. | File Preview and Review panes dynamically soft-wrap and adapt to container resizing without horizontal clipping. |
