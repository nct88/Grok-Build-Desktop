# Grok Build Desktop 0.5.64

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.64 khắc phục triệt để lỗi không nhận diện được Grok Build IDE khi chạy trong các môi trường sandbox / quản lý clone profile (GrokCloneManager, AntigravityCloneManager), tự động phát hiện phiên bản IDE đã cài đặt (v1.0.12) và chuẩn hóa nội dung hiển thị trong các hộp thoại và cài đặt. | Release 0.5.64 resolves Grok Build IDE detection failures when running within sandboxed or cloned profile managers (GrokCloneManager, AntigravityCloneManager), automatically detects and displays the installed IDE version (v1.0.12), and standardizes messaging across dialogs and settings. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Nhận diện môi trường host Windows đa nguồn: Bổ sung cơ chế phát hiện đường dẫn người dùng thực thông qua phân tích regex đường dẫn gốc (`C:\Users\<user>`), biến môi trường `USERNAME`, `SystemDrive`, truy vấn Windows Registry Shell Folders (`HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders` -> `Local AppData`) và quét tự động `C:\Users\*`. Đảm bảo nút "Mở IDE" luôn tìm thấy file cài đặt thực tế trên máy mà không bị nhầm lẫn bởi đường dẫn sandbox của clone manager. | Multi-source host profile discovery: Introduces fallback host path discovery via regex root extraction (`C:\Users\<user>`), `USERNAME` and `SystemDrive` environment variables, Windows Registry Shell Folders query, and user directory scans. Ensures the "Open IDE" action reliably locates the host-installed IDE regardless of clone manager sandbox redirects. |
| Đọc và hiển thị phiên bản IDE tự động: Tự động trích xuất phiên bản từ file `VERSION` hoặc `package.json` của IDE (nhận diện chính xác `v1.0.12`), hiển thị phiên bản trên tooltip của nút "Mở IDE" và bảng thông tin trong Cài đặt. | Automatic IDE version extraction: Inspects the IDE `VERSION` manifest or `package.json` to extract the true installed version (identifying `v1.0.12`), surfacing it in the Open IDE button tooltip and Settings panel. |
| Chuẩn hóa văn bản và dọn dẹp câu chữ nháp: Loại bỏ hoàn toàn các cụm từ nháp phát triển như `(placeholder until landing is ready)`, `(demo link until the landing page is ready)`, `(link demo — chờ trang landing)` trong toàn bộ mã nguồn backend và renderer (song ngữ EN và VI). | Localization and dialog copy refinement: Eliminates development placeholder strings across main process menus and renderer localization bundles in both English and Vietnamese. |
| Hiển thị trạng thái IDE trong Cài đặt: Bổ sung trường trạng thái trực tiếp trong mục cấu hình Grok Build IDE, thông báo tức thì vị trí file exe và phiên bản đã tìm thấy. | Real-time IDE status in Settings: Displays live detection status in the Settings dialog, showing the detected product name, version, and full executable path. |
