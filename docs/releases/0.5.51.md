# Grok Build Desktop 0.5.51

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.51 bỏ thanh cuộn trên menu Thông tin phiên → Phiên: popup co giãn theo số trường của từng tài khoản và giữ toàn bộ hàng trong khung nhìn. | Release 0.5.51 removes the scrollbar from Session info → Session: the popover sizes to each account’s field list and keeps every row in view. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Menu usage không còn `overflow: auto` với chiều cao cố định; chiều cao bám nội dung tab đang mở, tối đa `100vh - 104px`, không hiện thanh cuộn. | The usage menu no longer uses a fixed-height `overflow: auto` box; height follows the active tab, capped at `100vh - 104px`, with no scrollbar. |
| Hàng phiên một dòng, giá trị dài cắt bằng ellipsis (hover vẫn hiện đủ, click vẫn sao chép). Nút Refresh usage / Manage billing chỉ hiện ở tab Ngữ cảnh và Tài khoản. | Session rows stay one line; long values ellipsize (full text on hover, copy on click). Refresh usage / Manage billing appear only on Context and Account. |
