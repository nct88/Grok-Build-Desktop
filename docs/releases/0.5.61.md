# Grok Build Desktop 0.5.61

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.61 giải quyết triệt để sự cố đen toàn màn hình khi đang xử lý trao đổi (streaming), tối ưu hóa hiệu năng render DOM, bổ sung cơ chế bắt lỗi và tự phục hồi khi tiến trình Renderer/GPU bị sự cố trên Windows. | Release 0.5.61 completely resolves the black screen issue occurring during conversation processing (streaming), optimizes DOM rendering performance, and introduces automatic crash recovery for Renderer and GPU process events on Windows. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| Triệt tiêu quá tải DOM & V8 OOM khi streaming: hoãn tokenization cú pháp (`highlightFence` tạo hàng nghìn thẻ `<span>`) trong lúc đang nhận delta liên tục, chỉ hoàn tất highlight đầy đủ khi turn kết thúc, ngăn chặn cạn kiệt bộ nhớ và giật lag giao diện. | Eliminate streaming DOM thrashing & V8 OOM: defers heavy syntax tokenization (`highlightFence` span generation) during active delta streaming, performing full highlighting upon turn finalization, preventing memory exhaustion and UI freezing. |
| Bổ sung cơ chế tự phục hồi lỗi Renderer Crash: đăng ký bộ lắng nghe `render-process-gone` và `unresponsive` trong `main.cjs` để ghi log mã lỗi/nguyên nhân và tự động đưa ra tùy chọn khôi phục (Reload) an toàn thay vì để cửa sổ kẹt ở màn hình đen. | Electron renderer crash recovery: registers `render-process-gone` and `unresponsive` handlers in `main.cjs` to log crash details and present a safe recovery reload dialog instead of hanging on a black surface. |
| Tăng cường độ ổn định GPU trên Windows: kích hoạt cờ `--disable-gpu-process-crash-limit` và đăng ký bộ lắng nghe `child-process-gone` (GPU) để bảo vệ giao diện trước các sự cố mất ngữ cảnh đồ họa (GPU Context Loss). | Windows GPU stability safeguards: enables `--disable-gpu-process-crash-limit` and handles `child-process-gone` (GPU) events to guard the UI against GPU context losses. |
| Giới hạn an toàn dữ liệu file diffs qua IPC: kiểm soát độ dài chuỗi văn bản trong `onFileWrite` và `renderCliDiff`, loại bỏ nguy cơ nghẽn kênh truyền IPC khi Agent chỉnh sửa các tệp dữ liệu lớn. | Safe IPC payload boundaries: bounds diff string lengths in `onFileWrite` and `renderCliDiff`, preventing IPC buffer saturation and memory spikes when the Agent edits massive files. |
