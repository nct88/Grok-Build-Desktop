# Grok Build Desktop 0.5.49

<!-- release:vi -->
<!-- release:en -->

| Tiếng Việt | English |
|---|---|
| Bản 0.5.49 làm Desktop tương thích an toàn với Grok CLI 1.0.13, giữ hook permission có yêu cầu xác nhận ở trạng thái tương tác và sửa vòng đời worktree/process trên Windows. | Release 0.5.49 safely aligns Desktop with Grok CLI 1.0.13, keeps confirmation-required permission hooks interactive, and fixes Windows worktree/process lifecycle behavior. |

## Nội dung phát hành / Release highlights

| Tiếng Việt | English |
|---|---|
| `dontAsk` không còn bị host tự cấp quyền; Auto chỉ tự duyệt read/search/think/fetch. Hook `PreToolUse` trả về `ask` luôn hiển thị thẻ xác nhận, kể cả Full access. | `dontAsk` is no longer auto-approved by the host; Auto only approves read/search/think/fetch. A `PreToolUse` hook with `ask` always shows a confirmation card, including in Full access. |
| Thẻ permission giữ metadata của hook, lý do, ngữ cảnh bổ sung và tất cả lựa chọn option do CLI trả về. | Permission cards retain hook metadata, reason, additional context, and every CLI-supplied option. |
| Resume session không truyền lại worktree flags; ngắt kết nối trên Windows dùng process-tree termination để không sót process Grok con. | Resumed sessions omit worktree flags; Windows disconnect uses process-tree termination so child Grok processes are not left behind. |
